# Security

Found a way t3agent37 could be made to do harm? The Agent37 API key leaving your computer or getting onto a machine, a machine or its T3 server reachable by someone it shouldn't be, a wake link or T3 token kept or sent where it shouldn't be, the local proxy or MCP server answering something other than your own computer, an update taken without its signature. Please tell the maintainer privately first, not in an issue:

- **Report a vulnerability** under this repo's Security tab. GitHub keeps it private between you and the maintainers.

Say what it is, how to make it happen, and t3agent37's version (Settings, at the bottom). Every report gets read. Once it's fixed, it can be made public, crediting you if you'd like.

Only the latest release gets fixes: t3agent37 updates itself, so that's the one to try it on.

Problems in Agent37 Cloud or T3 Code themselves belong to them: [Agent37](https://www.agent37.com), [T3 Code](https://github.com/pingdotgg/t3code).
